# Home

VRPSolver is a Branch-Cut-and-Price based exact solver for vehicle routing and some related problems.

This documentation covers the **Julia interface** of VRPSolver. Installation instructions are available in the [VrpSolver.jl repository](https://github.com/tbulhoes/VrpSolver.jl). Demo applications are available in the [VRPSolverDemos repository](https://github.com/artalvpes/VRPSolverDemos).
